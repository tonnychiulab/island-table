# SDD：島嶼餐桌（台灣食物與特有物種三部曲）

狀態：**已確認第一可玩版設計**（僅藍鵲播種一局）；夜市七攤、七家灣規格保留為後續，本輪未改規則  
日期：2026-09-25  
範圍：三款可獨立遊玩、共用同一份圖鑑資料的小遊戲；**第一可玩建置只做藍鵲播種一張地圖**

## 1. 這份文件要決定什麼

用 [Kenney](https://kenney.nl/) 的免費素材與 Godot 範例，做三款「玩得起來」的遊戲，讓玩家認識台灣的食物，以及跟這些食物相關的植物、動物、魚類、昆蟲。

成功標準：

- 每一款都有一個 3–8 分鐘能打完的核心循環，不是圖鑑瀏覽器。
- 玩家打完一局，能說出至少一道食物的名字，以及一種生物為什麼跟這道食物或這個棲地有關。
- 保育類不會被做成食材。食材與保育對象用不同規則出現。

### 1.1 第一可玩版（已決定）

| 項目 | 決定 |
| --- | --- |
| 受眾 | 國小教室。老師投影螢幕。短句口語繁中，不是教科書。英文與觀光模式之後再做。 |
| 平台 | **靜態網頁**（非桌面 exe、非 Godot）。版面 1280×720，老師用瀏覽器打開並投影。規則預留觸控；v1 用滑鼠／點擊。 |
| 聲音 | 靜音：無音效。老師把畫面上每一句話念給全班聽。 |
| 範圍 | **只做藍鵲播種一張地圖、一局教室循環。** 夜市七攤、七家灣留在本文件當後續遊戲，規則本輪不變。 |
| 不做（v1） | 帝雉、梅花鹿、寬尾鳳蝶；英文；自製剪影；音效；遊戲頁不連到老師頁。 |

## 2. Kenney 研究結論

官網定位是遊戲素材庫，不是台灣主題包。2026-09 實測：

| 項目 | 事實 |
| --- | --- |
| 授權 | 素材頁皆為 [CC0](https://kenney.nl/support)。可商用。署名非必須；若署名只寫 “Kenney”。不可使用 Kenney 標誌。 |
| 風格 | 乾淨、圓潤、低面數或像素。全庫同一套審美，適合當遊戲殼。 |
| 規模 | All-in-1 約 60,000+ 檔（2D、3D、UI、音效、字型）。個別包可免費下載。 |
| 引擎範例 | [Starter Kits](https://kenney.nl/starter-kits) 皆為 Godot：Match-3、Racing、3D Platformer、FPS、City Builder、Basic Scene。 |
| 跟本題最相關的包 | Food Kit（3D，2.0 重製）、Pixel Platformer Food Expansion、Pixel Platformer Farm Expansion、Tiny Farm、Fish Pack（2D 向量）、Animal Pack（3D）、Nature Kit、Foliage、Mini Forest、City Kit、UI、Input Prompts、介面音效。 |

缺口（必須寫進設計，不能用素材硬湊）：

- 沒有台灣特有種：台灣黑熊、台灣藍鵲、帝雉、櫻花鉤吻鮭、寬尾鳳蝶、愛玉都沒有對應模型。
- Animal Pack Redux 一類是熊、牛、鸚鵡、鯨魚等通用動物，外形不能冒充特有種。
- Food Kit 是通用西式／幾何食物（漢堡、甜甜圈、水果塊），沒有滷肉飯、蚵仔煎、珍珠、鳳梨酥。
- 沒有繁中圖鑑文案。

因此採用兩層美術：

1. **Kenney 殼**：場景、UI、按鈕、粒子、佔位道具、程式骨架。（v1 不用音效。）
2. **自製圖鑑層**：特有種與台灣菜的剪影、名稱、一句話事實。**第一可玩版用名稱＋色標大字**，夠教室後排看清即可；剪影等這一局玩順再做。對外展示前必須換成自製圖，避免玩家把「Kenney 的牛」記成台灣動物。

## 3. 三款遊戲怎麼分工

同一世界觀：**島嶼餐桌**。食物從棲地來，棲地裡有不該被吃的物種。三款遊戲讀同一份 `atlas.json`，各自只負責一種玩法。

| 遊戲 | 玩家身份 | 玩法 | 主要認識 | 建置順序 |
| --- | --- | --- | --- | --- |
| **藍鵲播種** | 台灣藍鵲 | 路徑播種（點節點連線） | 山蘇、愛玉、黑熊不可煮、藍鵲特有 | **第一可玩（僅此一局）** |
| 夜市七攤 | 夜市學徒 | 限時配菜 | 台灣菜與食材植物 | 後續 |
| 七家灣 | 櫻花鉤吻鮭 | 逆流，且到不了海 | 魚類、水棲昆蟲、保育 | 後續 |

**建議製作順序（已決定）：藍鵲播種 → 夜市七攤 → 七家灣。** 第一可玩版用藍鵲一局驗證教室投影、老師點擊、靜音朗讀流程。夜市、七家灣規格見第 5、6 節，本輪不改規則。

## 4. 內容倫理（實作前就定死）

每筆資料只有一個身份標籤：

- `food`：可以出現在訂單與料理。
- `protected`：只能出現在保育目標、不能進食譜。
- `habitat`：棲地裡的生物，不進廚房，也不當獎品烹煮。

硬規則（已決定）：

- **受保護的動物永遠不能進鍋。** 植物即使受保護，仍可當食物出現。
- 玩笑只能是「走錯路線」，**絕不是煮熊**。路線同時經過黑熊與鍋才算失敗；單獨點黑熊或單獨點鍋不算煮熊。
- 玩法可以誇張（「播種」是遊戲動詞）。物種名稱與能不能吃必須正確。
- **不要宣稱**台灣藍鵲會耕種山蘇或愛玉。不要使用「物競天擇」。不要點名特定原住民族。
- 台灣黑熊、台灣藍鵲、帝雉、台灣梅花鹿、櫻花鉤吻鮭、寬尾鳳蝶、珠光鳳蝶標為 `protected` 或 `habitat`。畫面不出現「烤熊」「釣鮭做成菜」。
- 可食用魚（虱目魚、櫻花蝦、烏魚）與保育魚分冊。七家灣關卡裡，外來鱒魚是需避開或標記的壓力，不是料理。
- 第一版不把飛魚祭、小米祭等祭儀做成計分關卡。山產只寫日常食材（山蘇、桂竹筍、小米），並在圖鑑註明族群與地區，不假裝是全台通用菜。
- 每筆事實附來源類型：林業及自然保育署、特有生物研究保育中心、農業部水產試驗所，或教科書等級的公開資料。沒來源的句子不上線。
- **孩子看的畫面不放引用。** 另做一頁「老師頁」，列出山蘇、愛玉、台灣黑熊、台灣藍鵲的公開來源：寫機構名稱與要核對的事實即可（例如林業及自然保育署、特有生物研究保育中心）；不確定具體網頁時不捏造頁名或 URL。

## 5. 遊戲一：夜市七攤（後續，本輪規則不變）

> 非第一可玩範圍。規格保留，待藍鵲播種教室一局驗證後再排程。

### 幻想

一週七個晚上，七個攤。客人用短句點餐。你在輸送帶上把對的食材送進鍋。做對一道菜，圖鑑翻開這道菜的「從哪裡來」：植物、漁法或節氣，而不是背課文。

### 核心循環（約 4 分鐘一晚）

1. 抽一張訂單（菜名＋兩個必要食材）。
2. 食材從畫面上方落下，玩家點擊或拖進對的槽。限時。
3. 送出正確組合：攤位升級一格，解鎖一張圖鑑。
4. 送錯：客人離開，該菜的錯誤項寫進「差一點」清單，下一單會再出現一次。
5. 七晚結束：一張「這週菜單」，列出學會的菜與對應生物。

### 為什麼有趣

壓力在夜市節奏，知識在送出之後的半張卡片，不在答題。卡片只留一句，例如：「愛玉不是洋菜，是台灣特有的愛玉子果實搓出來的。」

### Kenney 對應

- 骨架：Starter Kit **Match-3**（Godot）。改成「三個同類食材消掉並填入訂單」，不必從零寫盤面。
- 畫面殼：UI Pack、Input Prompts、介面音效。
- 佔位食物：Food Kit 或 Pixel Platformer Food Expansion 的幾何塊，上面貼自製文字標籤（滷肉、蚵、珍珠、愛玉）。
- 城市底：City Kit 只當遠景色塊，不建寫實夜市街。

### 第一版菜單（12 道，每道綁一個非保育生物或植物）

| 菜 | 綁定 | 玩家該記住的一句 |
| --- | --- | --- |
| 滷肉飯 | 稻 | 台灣主食是米，不是麵包。 |
| 牛肉麵 | 小麥麵＋清燉／紅燒兩派 | 這碗麵是戰後台灣發展出來的。 |
| 蚵仔煎 | 牡蠣 | 西海岸養蚵，蛋煎是攤上的火候。 |
| 珍珠奶茶 | 茶＋木薯粉珍珠 | 1980 年代從台中茶飲鋪走進世界。 |
| 鳳梨酥 | 鳳梨 | 餡是鳳梨，不是鳳梨造型。 |
| 愛玉冰 | 愛玉（*Ficus pumila* var. *awkeotsang*） | 特有變種，果實搓出果膠。 |
| 芋圓 | 芋頭 | 客家與夜市都常見的澱粉點心。 |
| 山蘇炒蛋 | 山蘇（鳥巢蕨） | 林下蔬菜，不是一般菠菜。 |
| 筊白筍 | 筊白筍 | 與真菌共生的膨大莖，產季很短。 |
| 虱目魚湯 | 虱目魚 | 養殖魚，不是溪流保育魚。 |
| 櫻花蝦 | 櫻花蝦 | 東港沿岸漁獲，不是櫻花鉤吻鮭。 |
| 茶葉蛋 | 茶 | 茶是作物；茶園也是淺山棲地。 |

第七晚的隱藏單是「認錯懲罰」：若玩家把櫻花蝦拖進鮭魚槽，訂單失敗，並強制翻開保育卡（見遊戲二）。

## 6. 遊戲二：七家灣（後續，本輪規則不變）

> 非第一可玩範圍。規格保留，待後續再排程。

### 幻想

你是一尾櫻花鉤吻鮭。目標是游回七家灣溪上游產卵。這條魚陸封在雪山溪流，**關卡終點沒有海洋**。游到「海」的出口會被擋回，並出現一句話：你的祖先被山隔在溪裡。

### 核心循環（單局 3–6 分鐘）

1. 一鍵或方向鍵往上游。
2. 吃水棲昆蟲維持體力（食物網，不是人類菜單）。
3. 避開或標記外來鱒魚（牠們搶產卵場）。
4. 收集三種溪流植物或昆蟲印章，打開產卵點。
5. 成功：圖鑑串起「昆蟲 → 幼魚 → 成魚 → 產卵場」。失敗可重試，產卵場位置不變。

### 為什麼有趣

輸贏規則本身就是生物學：到得了上游、到不了海。跟夜市的櫻花蝦形成對照，專治「名字很像所以是同一種」的誤解。

### Kenney 對應

- 魚的佔位：Fish Pack 的剪影，著色成「深櫻色背、產卵季側線」的示意，圖鑑用自製側視圖標明是示意，不是檢索圖。
- 溪谷：Nature Kit、Mini Forest、Foliage 的石頭與樹，俯視或側視 2D 即可，不必上 3D Platformer。
- 音效：水聲與界面音用 Kenney Audio。（後續版本；第一可玩版全遊戲靜音。）

### 第一版物種

| 名稱 | 標籤 | 在遊戲裡的角色 |
| --- | --- | --- |
| 櫻花鉤吻鮭 | protected | 玩家。陸封、產卵洄游只在溪內。 |
| 台灣石賓（或同溪常見蝦虎，定稿前核對種名） | habitat | 同溪鄰居，不可釣起當菜。 |
| 外來鱒魚（虹鱒一類，文案寫「外來鮭鱒」） | habitat | 障礙。說明放流會擠壓產卵場。 |
| 蜉蝣、石蠶蛾幼蟲 | habitat | 體力來源，食物網底層。 |
| 櫻花蝦 | food | 不出現在這條溪。只在失敗對照卡出現，連回夜市。 |

魚類食材（虱目魚、櫻花蝦、烏魚子）留在夜市圖鑑，不放進溪流操作。

## 7. 遊戲三：藍鵲播種（第一可玩版）

> **第一可玩建置只做本節 v1 一局。** 帝雉、梅花鹿、寬尾鳳蝶、解鎖夜市訂單、自製剪影等屬後續擴充，不進 v1。

### 幻想（長期）

一群台灣藍鵲在淺山與森林之間飛。你畫一條路線；遊戲動詞是「播種」，不是宣稱藍鵲真的會種田。結算在教「什麼可以吃、什麼只能看」：植物可當食物，受保護的動物不能進鍋。

### 7.1 v1 教室一局（已決定）

**目標：** 老師投影，滑鼠點節點連出路線，按「出發」判定；全班聽老師朗讀畫面句子。成功後沒有下一張地圖。

#### 畫面配置（左 → 右）

| 位置 | 節點 | 標籤色 | 互動 |
| --- | --- | --- | --- |
| 左上 | 全螢幕按鈕 | — | 標籤「全螢幕」。用 Fullscreen API；**不**在載入時強制全螢幕。靠近藍鵲，不蓋住黑熊或鍋。 |
| 左 | 藍鵲 | 藍 | 路線起點，開局自動接上。**不是可點節點**，也不能送進鍋。 |
| 中 | 山蘇、愛玉 | 綠 | 可點 |
| 右 | 黑熊、鍋 | 黑熊深色、鍋紅色 | 可點 |

節點是「名稱＋色標」，字要夠大，教室後排能讀。剪影等本局玩順再加。無音訊、無老師頁連結。

#### 輸入

1. 老師點節點；畫面從藍鵲起畫出連線，經過被點到的節點。
2. **點的順序不影響結果**；只看路線上有哪些節點。
3. 再點已選節點：無反應（不重複、不取消）。
4. 「出發」之前，「重來」清空整條路線。

#### 判定（只在按「出發」時）

| 條件 | 結果 |
| --- | --- |
| 路線上同時有山蘇與愛玉，**且**不是（黑熊 **且** 鍋） | **成功**。只有黑熊、或只有鍋，仍算成功。 |
| 路線上同時有黑熊與鍋 | **失敗**（即使兩種植物也都在路線上）。 |
| 缺山蘇、缺愛玉、或兩者都缺 | **不判失敗**，也不顯示打獵句。路線保留。畫面說「還缺山蘇」「還缺愛玉」，或缺兩者都說。 |

#### 文案（留在畫面上）

失敗句（直到按「再試一次」）：

> 有人以前靠山林生活，打獵有自己的規矩。現在這些動物受保護，遊戲裡不能拿去煮。

成功句（留在畫面上；**沒有下一關地圖**）：

> 山蘇可以炒來吃。愛玉果實可以做成愛玉冰。藍鵲是台灣特有的鳥。播種是遊戲。

#### 重開給下一組（已決定）

- 失敗後「再試一次」、成功後「再玩一次」：都清空路線與句子，**地圖本身不變**，下一組不用重開程式。

#### 老師頁（非孩子畫面）

另頁列出山蘇、愛玉、台灣黑熊、台灣藍鵲的公開事實來源。寫**機構＋事實**即可（例如林業及自然保育署、特有生物研究保育中心）；不確定具體頁面時不捏造標題或 URL。

### 7.2 後續擴充（非 v1，構想保留）

以下不進第一可玩版，規則細節待之後再開：

1. 地圖上有 4–6 個空地與一條已存在的獸徑；一筆畫不交叉等進階路線規則。
2. 傳粉昆蟲／寬尾鳳蝶蜜源加成。
3. 結算後標 `food` 的植物送去夜市七攤當新訂單；標 `protected` 的只進觀察冊。
4. 觀察區物種：帝雉、梅花鹿；獼猴製造路線壓力等。

### Kenney 對應（v1）

- 地圖：Nature Kit／Foliage 的俯視塊即可；節點以大色塊＋文字為主。
- 鳥：不用 Kenney 鸚鵡冒充藍鵲。v1 用藍色標籤／色塊即可；剪影後做。
- 無音效。UI Pack、Input Prompts 可當按鈕殼。

### 物種（v1 進場 vs 後續）

| 名稱 | 標籤 | v1 | 角色 |
| --- | --- | --- | --- |
| 台灣藍鵲 | protected | 進場 | 路線起點。特有種。不可點、不可進鍋。 |
| 山蘇 | food | 進場 | 可點。成功句：可炒來吃。 |
| 愛玉 | food | 進場 | 可點。成功句：果實可做成愛玉冰。 |
| 台灣黑熊 | protected | 進場 | 可點。與鍋同時在路線上才失敗。 |
| 鍋 | （路線節點，非物種） | 進場 | 可點。紅色標籤。 |
| 帝雉、梅花鹿、寬尾鳳蝶、珠光鳳蝶、獼猴、針葉樹／樟樹等 | — | **不進 v1** | 見後續擴充與舊構想表。 |

## 8. 共用資料與架構

```text
site/index.html           藍鵲播種第一可玩（孩子頁）
site/teacher/index.html   老師頁（機構＋事實；遊戲頁不連過去）
docs/                     設計文件（不發布到靜態站）
atlas.json                （後續）菜、物種、標籤、一句話、來源
art/kenney/               （後續）只放 CC0 原檔，不改作者中繼資料
art/atlas/                （後續）自製剪影與標籤
```

一筆圖鑑最少欄位：`id`、`name_zh`、`name_latin`（生物才有）、`kind`（dish / plant / animal / fish / insect）、`tag`（food / protected / habitat）、`one_liner`、`source`、`links`（會觸發哪一款遊戲的哪個事件）。

程式只認 `tag`。廚房／鍋相關邏輯讀到 `protected` 動物直接拒絕，不靠關卡設計師記得。

技術選擇（已決定，第一可玩）：

- **靜態 HTML／CSS／JS**，無建置步驟、無 npm、無 Godot、無 Kenney 素材依賴。
- 發布目錄：`site/`。遊戲：`site/index.html`。老師頁：`site/teacher/index.html`（路徑 `/teacher`）。
- 解析度：版面 **1280×720**（小視窗等比縮小）；老師用瀏覽器投影。
- 文字：短句口語**繁體中文**（教室用）。英文之後再做。
- 音效：v1 **靜音**。
- 夜市七攤、七家灣若日後改引擎，可另開；本輪不改其規則。

## 11. 風險

- **認錯種。** 最大風險。緩解：拉丁名＋來源＋禁止用 Kenney 動物當正式形象；玩法誇張不改物種能不能吃的事實。
- **素材風格不台灣。** 接受。台灣感放在菜名、標籤、調色與規則，不放在「把 Kenney 城市皮膚改成台北」。
- **原住民內容做輕。** 第一版只收日常食材，祭儀不做關卡；不點名特定原住民族。
- **範圍膨脹。** 三款同時開工會停。**先做藍鵲播種教室一局**，夜市與七家灣後做。
